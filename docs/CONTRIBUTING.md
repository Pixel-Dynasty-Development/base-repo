# Contributing to Pixel Dynasty Templates 🚀

This repository serves as the core "engine" for Pixel Dynasty Development projects.

## 🛠 Development Workflow

1. **Branching Strategy**: Use feature branches (`feature/name`) for all new components.
2. **Commit Messages**: Keep them concise (e.g., `feat: added contact form`).
3. **Pull Requests**: All changes must be merged via a PR to ensure GitHub Actions run.

## ✅ Quality Checklist

- Wrap all new views in a single `<div>` for transitions.
- Use semantic Tailwind classes (e.g., `text-primary`) instead of hex codes.
- Document new config options in `THEMING.md`.
